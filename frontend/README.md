# Frontend

Frontend estático do Veredicta.

- `index.html`: Pesquisa.
- `processo.html`: Ficha do processo.
- `historico.html`: Histórico e jurimetria.
- `assets/css`: estilos.
- `assets/js/config.js`: configuração pública.
- `assets/js/pages`: scripts específicos de cada página.

As páginas e conteúdos visuais foram preservados; a reorganização altera apenas a estrutura de arquivos e os caminhos dos assets.
